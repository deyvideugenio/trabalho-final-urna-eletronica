O que é `candidatos.txt`?

É um arquivo de texto simples (TXT) que você deve criar. Ele servirá como o "banco de dados" dos candidatos. Cada linha representa um candidato.

Formato da Linha:

Nome, Numero, Partido, Estado, Cargo 

José da Silva, 7321, PTB, MG, F
Maria do Carmo, 7321, PCB, SP, F
Pedro de Azevedo, 731, PTB, PR, S
Paulo da Cunha, 15, PXB, SP, P
Emília Santos, 15, PCT, MG, G

O que é `eleitores.txt`?

Similar ao anterior, é o arquivo TXT que armazena os eleitores aptos a votar. Cada linha é um eleitor.

Formato da Linha:

Nome, RG, Título de Eleitor, Município, Estado 

Pedro de Assis, MG17845369, 015443020272, Formiga, MG
Carla Machado, SP156987456, 848242120221, Osasco, SP
Luís Silva, RS16457956, 73278703030, Santa Maria, RS

Nosso Objetivo 🎯

Bem-vindos ao trabalho final! O desafio de vocês é desenvolver uma Urna Eletrônica Simplificada usando Python.

Este projeto visa reforçar, na prática, os conceitos de listas, dicionários, funções e manipulação de arquivos (texto e binário) que vimos em sala de aula.

Vocês criarão um sistema com um menu que permite ao mesário carregar os dados de candidatos e eleitores, iniciar a votação (coletando votos para 5 cargos), salvar esses votos, e, por fim, apurar os resultados e gerar um boletim de urna.

Funcionalidades (Roteiro) 🚀

1

Menu Principal

O programa deverá exibir o seguinte menu para o mesário. As opções 3, 4 e 5 só devem funcionar após as opções 1 e 2 serem executadas. 

1 - Ler arquivo de candidatos
2 - Ler arquivo de eleitores
3 - Iniciar votação
4 - Apurar votos
5 - Mostrar resultados
6 - Fechar programa
2

Leitura de Candidatos

O programa deve perguntar o nome do arquivo (ex: `candidatos.txt`) e ler os dados, salvando-os em estruturas internas (listas, dicionários, etc.).

Cargos e Dígitos:

Código Cargo Dígitos
F Deputado Federal 4
E Deputado Estadual 5
S Senador 3
G Governador 2
P Presidente 2
3

Leitura de Eleitores

Similar ao passo 2, o programa deve ler o arquivo de eleitores (ex: `eleitores.txt`) e carregar os dados (Nome, RG, Título, Município, Estado) para a memória.

4

Coleta de Votos

Esta é a função principal. O mesário deve primeiro informar a UF da urna.

Antes de cada voto, o mesário digita o Título de Eleitor. O sistema deve encontrar o eleitor e mostrar seu nome e estado.

A ordem de votação é: 1º Dep. Federal, 2º Dep. Estadual, 3º Senador, 4º Governador, 5º Presidente.

Regra de Estado: Exceto para Presidente, eleitores só podem votar em candidatos do seu próprio estado.

O sistema deve aceitar 'B' para Voto em Branco e 'N' (ou um número inválido) para Voto Nulo, sempre pedindo confirmação. 

Informe o Título de Eleitor: 015443020272
Eleitor: Pedro de Assis
Estado: MG

Informe o voto para Deputado Federal: 7321
Candidato José da Silva | PTB
Confirma (S ou N)? S

Informe o voto para Deputado Estadual: 73215
Candidato não encontrado! Voto Nulo.
Confirma (S ou N)? N
...
Voto registrado com sucesso!
Registrar novo voto (S ou N)? N
5

Persistência de Dados (Pickle)

Ao final de cada votação completa (os 5 cargos), o voto deve ser salvo em um arquivo binário (ex: `votos.bin`).

Use a biblioteca pickle do Python para salvar um dicionário contendo os votos daquele eleitor. 

# Exemplo da estrutura a ser salva com pickle
voto = {
    "UF": "MG",
    "F": 7321,  # Dep. Federal
    "E": 18151, # Dep. Estadual
    "S": "B",   # Senador (Branco)
    "G": "N",   # Governador (Nulo)
    "P": 18     # Presidente
}

# Em seu código, você usará pickle.dump(voto, arquivo)
# em modo 'ab' (append binary)
6

Apuração dos Votos

Ao selecionar a opção 4 (Apurar Votos), o programa deve ler o arquivo binário (`votos.bin`) usando `pickle.load()` repetidamente (em um loop `try/except EOFError`).

Ele deve contabilizar, para cada candidato, a quantidade de votos recebida, além do total de brancos e nulos.

7

Divulgação (Boletim de Urna)

Após a apuração (Passo 6), a opção 5 (Mostrar Resultados) deve gerar um arquivo de texto (`boletim.txt`), formatado de maneira clara, mostrando os resultados.

O boletim deve incluir o total de eleitores aptos, total de votos nominais, brancos, nulos, e a lista de candidatos votados com seus respectivos totais e porcentagens.

Desafio Extra 1 / 2 (+2,5 Pontos)

Para ganhar 2,5 pontos extras, após gerar o boletim de urna, o programa deverá, utilizando a biblioteca matplotlib, criar e exibir, para cada cargo da eleição, um gráfico de barras mostrando de forma gráfica o resultado.

Crie em seu código a função gera_grafico(título, votos), onde votos é um dicionário (chave = nome do candidato, valor = quantidade de votos) e título é uma string para o gráfico.

Sugestão Avançada: Streamlit

Quer impressionar? Em vez de apenas salvar o gráfico, use Streamlit (pip install streamlit) para criar um "dashboard" web interativo que exibe os gráficos de forma profissional. 

# Este dicionário deve ser montado a partir da apuração
votos_presidente = {
    "João da Silva": 150, 
    "Carlos Mariano": 130, 
    "Maria da Glória": 90, 
    "Carla Nascimento": 100
}
gera_grafico("Apuração - Presidente", votos_presidente)

Desafio Extra 2 / 2 (+2,5 Pontos)

Para ganhar mais 2,5 pontos, implemente um Controle de Votação. Um eleitor não pode votar duas vezes.

Requisitos:

  • 🛡️
    Durante a "Coleta de Votos" (Funcionalidade 4), após o mesário digitar o Título de Eleitor, o sistema deve verificar se aquele título já consta em uma lista de "eleitores que já votaram".
  • ❌
    Se o eleitor já votou, exiba uma mensagem de erro (ex: "Eleitor já votou. Votação não permitida.") e impeça o início da votação.
  • ✅
    Se o eleitor ainda não votou, permita a votação normalmente. Após o voto ser confirmado e salvo, adicione o Título de Eleitor desse eleitor à lista de "eleitores que já votaram".
  • 💾
    Persistência: Essa lista de controle deve ser persistente. Salve-a em um arquivo (ex: `eleitores_que_votaram.txt` ou usando `pickle`) toda vez que um novo voto for concluído e carregue-a no início do programa.
